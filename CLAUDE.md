## Project

Marketing site for Uplyft Business. It's a static client-side SPA hosted on GitHub Pages. There is no server runtime: don't add server functions, SSR, or anything that needs secrets at runtime. `README.md` is a public company overview, so keep technical notes out of it and put them here.

## Commands

- `npm run dev`: Vite dev server
- `npm run build`: static build into `dist/`. Set `BASE_PATH=/<repo-name>` to reproduce the GitHub Pages build (in Git Bash on Windows, also set `MSYS_NO_PATHCONV=1` or the path gets mangled).
- `npm run preview`: serve `dist/`
- `npm test`: Vitest, run once (jsdom, `src/**/*.{test,spec}.{ts,tsx}`)
- Single test: `npx vitest run src/test/app-routing.test.tsx`, or `-t "<test name>"`
- `npm run lint`: ESLint with Prettier via eslint-plugin-prettier. Existing files have many Prettier-only errors.
- `npx tsc --noEmit`: typecheck

## Architecture

Vite + React 19 + TanStack Router (file-based) + TanStack Query, Tailwind v4, shadcn/ui (`src/components/ui/`).

- **Entry**: [index.html](index.html) holds the static `<head>`: title, description/OG meta, fonts and favicon. Page metadata goes here rather than in route `head()`, since there's no SSR to render it. [src/main.tsx](src/main.tsx) mounts `RouterProvider`.
- **Base path**: [vite.config.ts](vite.config.ts) sets `base` from the `BASE_PATH` env var, and [src/router.tsx](src/router.tsx) passes `import.meta.env.BASE_URL` as the router `basepath`. Reference assets by importing them (e.g. `import logo from "@/assets/logo-dark.svg"`) or through `public/` paths in `index.html`. Hard-coded absolute URLs like `/foo.png` in JSX break under the Pages subpath.
- **Routing**: routes live in `src/routes/` (conventions in [src/routes/README.md](src/routes/README.md)). `src/routeTree.gen.ts` is generated by `@tanstack/router-plugin`; don't edit it by hand. [src/routes/__root.tsx](src/routes/__root.tsx) provides the 404 and error components and the QueryClientProvider, and must keep `<Outlet />`.
- **Deploy**: [.github/workflows/deploy.yml](.github/workflows/deploy.yml) runs on every push to `main` (Node version from `.nvmrc`). It runs `npm ci` and the tests, builds with `BASE_PATH` taken from `actions/configure-pages` (empty when a custom domain is set), copies `index.html` to `404.html` so deep links fall back to the SPA, and deploys `dist/`. Keep `package-lock.json` committed and in sync. One-time repo setup: **Settings → Pages → Source: GitHub Actions**.
- **Page content**: the site is one page, [src/routes/index.tsx](src/routes/index.tsx), with its copy held in local arrays at the top of the file. The "Book now" buttons link to the `#contact` section, which embeds a Tally form (`src/components/TallyForm.tsx`, form id `yXXWpW`). Tally stores the submissions, so the site needs no backend.
- **Styling**: theme tokens are CSS variables in [src/styles.css](src/styles.css), exposed to Tailwind through `@theme inline`. To add a color, define `--name` and register `--color-name: var(--name)`. Brand utilities include `brand-deep`, `highlight`, `brand-gold` and `font-display` (Lora); the body font is Manrope.
