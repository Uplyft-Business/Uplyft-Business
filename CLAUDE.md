## Project

Marketing site for Uplyft Business. It's a static client-side SPA hosted on GitHub Pages. There is no server runtime: don't add server functions, SSR, or anything that needs secrets at runtime. `README.md` is a public company overview, so keep technical notes out of it and put them here.

## Commands

- `npm run dev`: Vite dev server
- `npm run build`: static build into `dist/`, then [scripts/route-pages.mjs](scripts/route-pages.mjs) copies `index.html` to `dist/<route>.html` for each page in `src/routes/`, so GitHub Pages serves deep links like `/resources` with a 200 instead of only through `404.html` (search engines and link previews skip 404s). Set `BASE_PATH=/<repo-name>` to reproduce the GitHub Pages build (in Git Bash on Windows, also set `MSYS_NO_PATHCONV=1` or the path gets mangled).
- `npm run preview`: serve `dist/`
- `npm test`: Vitest, run once (jsdom, `src/**/*.{test,spec}.{ts,tsx}`)
- Single test: `npx vitest run src/test/app-routing.test.tsx`, or `-t "<test name>"`
- `npm run lint`: ESLint with Prettier via eslint-plugin-prettier. Existing files have many Prettier-only errors.
- `npx tsc --noEmit`: typecheck

## Architecture

Vite + React 19 + TanStack Router (file-based) + TanStack Query, Tailwind v4, shadcn/ui (`src/components/ui/`).

- **Entry**: [index.html](index.html) holds the static `<head>`: title, description/OG meta, fonts and favicon. Page metadata goes here rather than in route `head()`, since there's no SSR to render it. [src/main.tsx](src/main.tsx) mounts `RouterProvider`.
- **Base path**: [vite.config.ts](vite.config.ts) sets `base` from the `BASE_PATH` env var, and [src/router.tsx](src/router.tsx) passes `import.meta.env.BASE_URL` as the router `basepath`. Reference assets by importing them (e.g. `import logo from "@/assets/logo.svg"`) or through `public/` paths in `index.html`. Hard-coded absolute URLs like `/foo.png` in JSX break under the Pages subpath.
- **Routing**: routes live in `src/routes/` (conventions in [src/routes/README.md](src/routes/README.md)). `src/routeTree.gen.ts` is generated by `@tanstack/router-plugin`; don't edit it by hand. [src/routes/__root.tsx](src/routes/__root.tsx) provides the 404 and error components and the QueryClientProvider, and must keep `<Outlet />`.
- **Deploy**: [.github/workflows/deploy.yml](.github/workflows/deploy.yml) runs on every push to `main` (Node version from `.nvmrc`). It runs `npm ci` and the tests, builds with `BASE_PATH` taken from `actions/configure-pages` (empty when a custom domain is set), copies `index.html` to `404.html` so deep links fall back to the SPA, and deploys `dist/`. Keep `package-lock.json` committed and in sync. One-time repo setup: **Settings → Pages → Source: GitHub Actions**.
- **Pages**: all the copy and section components live in [src/components/sections.tsx](src/components/sections.tsx). The home page [src/routes/index.tsx](src/routes/index.tsx) shows every section in one scroll; each menu item also has its own page (`/what-we-fix`, `/how-we-work`, `/pricing`, `/operators`, `/client-stories`, `/faq`, `/move-by-move`) that reuses those sections with `bare` set under a `PageHeader`. Edit wording once in `sections.tsx` and it changes everywhere. `/resources` ([src/routes/resources.tsx](src/routes/resources.tsx)) lists the entries in [src/lib/resources.ts](src/lib/resources.ts): to add a PDF or template, put the file in `public/downloads/` (not `public/resources/`, which would clash with the `/resources` page on GitHub Pages) and add an entry with its `group` (checklist, framework or video); the page shows one section per group with filter buttons. PDFs open in an in-page viewer, templates download, and videos link out. `/privacy` ([src/routes/privacy.tsx](src/routes/privacy.tsx)) is a plain-language draft describing the services the site uses; update it when adding anything that collects data. Every page wraps itself in `SitePage` ([src/components/SiteLayout.tsx](src/components/SiteLayout.tsx)), the shared header and footer; its `title` prop sets the browser-tab title. `public/og-image.png` is the link-preview image, referenced by absolute URL from `index.html`. Header links go to those pages, and the current one is highlighted. The header has a Resources dropdown, and the full nav only shows from `xl` up because it doesn't fit narrower.
- **Diagnostic form**: every "Start the free diagnostic" button opens the Tally form `yXXWpW` in Tally's popup (`TallyPopupLink` in [src/components/TallyPopup.tsx](src/components/TallyPopup.tsx)); if Tally's embed script hasn't loaded, the link opens the hosted form in a new tab instead. Tally stores the submissions, so the site needs no backend. The form's questions are edited in Tally, not here.
- **Design reference**: the redesign mockups live in `New_Design/` (git-ignored, not part of the build).
- **Styling**: theme tokens are CSS variables in [src/styles.css](src/styles.css), exposed to Tailwind through `@theme inline`. To add a color, define `--name` and register `--color-name: var(--name)`. Brand utilities: `brand` (orange, buttons and accents), `sun` (yellow band), `ink` (headings, dark bands), `ink-soft`/`ink-muted`/`ink-line` (text and rules on ink), `cream` (alternate bands) and `body` (paragraph text). The only font is Roboto (300/400/500/700), loaded in `index.html`. Logos: `src/assets/logo.svg` for light backgrounds, `logo-light.svg` for ink.
